# ADR 0007: 演示模式架构（已废弃）

**日期**: 2026-08-01
**状态**: 已废弃（2026-08-04，演示模式功能取消）

## 废弃原因

应用侧"演示"按钮从未实现。代码评审（2026-08-04）发现整条链路——生成的 HTML 内嵌监听器、`lib/common.css` 的 `.present` reflow、`demo-write.js` 的演示模式监听器硬校验——在应用中没有任何触发入口，属死代码。经确认演示模式功能不再需要，本 ADR 作废。

遗留的代码侧设施（`.present` CSS 规则、`lib/common.js` 与各示例的监听器、`demo-write.js` 演示模式监听器校验、`app/CONVENTIONS.md` §演示模式监听器）暂未清理，留待后续随校验规则一并剥离。
