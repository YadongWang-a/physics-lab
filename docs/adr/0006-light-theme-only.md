# ADR 0006: 砍深色主题，浅色唯一

**日期**: 2026-08-01
**状态**: 已接受

## 背景

初始设计（见 `ball-spring.html` 等示例与 `CLAUDE.md` 旧约定）为**深色默认 + `[data-theme="light"]` 覆盖 + 🌙 按钮切换**。目标用户是物理老师在课堂投屏演示，浅色在投影仪与教室灯光下可读性更好；维护双主题使 CSS 变量、每个示例的 `themeBtn` JS、`[data-theme]` 规则块都要双份，增加 agent 模板复杂度且容易不一致。

## 选项

### A. 浅色唯一（推荐）

删深色变量、删 `[data-theme]` 规则、删 🌙 按钮及其 JS。`lib/common.css` 只保留浅色值。4 个示例 HTML 全部改造。

- 优势：CSS 与模板大幅简化；课堂投屏可读性最佳；agent 学到的是单一、清晰的样式约定
- 劣势：将来若要恢复深色需重写变量并改造所有示例，成本不低（故记此 ADR）

### B. 保留双主题

维持现状。

- 劣势：双份维护成本；老师大概率不用深色，切换能力成为死代码

### C. 浅色为默认但保留切换能力

折中。既然明确只要浅色，保留切换能力就是留死代码，徒增模板复杂度。

## 决策

**选 A —— 浅色唯一。**

## 影响

- `lib/common.css`：移除深色变量默认与 `[data-theme="light"]` 覆盖块，变量直接取浅色值
- 4 个示例 HTML：移除 `themeBtn`、`themeBtn` 的 JS、`[data-theme="light"]` 规则块
- Agent 模板与 system prompt：不再生成主题切换代码
- `CLAUDE.md`：约定从"暗色默认 + `[data-theme]` 切换"改为"浅色唯一"
- 此决定难逆转（恢复深色需重写变量 + 改造示例），未来读者会疑惑"为什么没有主题切换"，且是真实取舍（只要浅色 vs 丢深色用户）——故立此 ADR
