# 画布文字预算与信息通道归属

演示页画布只承载**短标注**（几何/结构标签、物理量符号+数值、≤6 字状态词；单条 ≤14 字、不含句读与推导符号）。所有成句信息按类型走唯一通道：讲解/推导 → 解析弹层 `.mpop`；颜色含义 → `setupScene.legend` 图例栏；阶段叙述 → `.phase` + 顶栏状态 seg；数值汇总 → `setupScene.hud` 关键量条（投影常驻）与侧栏 `.ro` 读数；标题 → `<title>` 与首行标记注释。页面已有标准件能表达的信息，画布不得复述。

**Status**: accepted

**Considered Options**:
- **画布自由书写**（原状）—— 模型倾向把图例说明、结论卡、动量守恒推导都画进画布；实测页面与图例栏/读数面板/阶段标签大量重复，画布拥挤且投影可读性差
- **只改模板** —— 骨架管不到 `drawScene` 内自绘文字，问题分散在每页
- **只改 drawing.md** —— 它是"绘制时按需读取"的手册；行为约束须进常驻 system prompt
- **新增 `.ro` 读数在投影可见** —— 演示模式侧栏整栏隐藏是有意的投影布局，改动更大且影响全站布局
- **选定方案：SKILL 提示词硬规则 + `hud` 关键量条标准件 + 静态软检查** —— 给合规出口（hud）同时禁复述，机械检查兜底

**Consequences**:
- `setupScene({hud:[{k,label,unit?}]})` 成为投影关键量的**唯一**画布邻近通道，`SC.hud(k, 值)` 在 render() 写值
- 画布文字密度由 `check_demo` 静态检查以 warning 级（`canvas-prose`）提示，存量页迁移期放行
- 演示模式（`body.present`）下侧栏隐藏、右缘标签隐藏，投影可见面 = 画布 + `.phase` + `.legendbar` + `.charts-row` + `.scene-hud`；新增画布邻近信息件须落在这一面内
- 提示词与 drawing.md 的措辞是行为主约束，静态检查只是兜底（正则无法判定语义重复）
