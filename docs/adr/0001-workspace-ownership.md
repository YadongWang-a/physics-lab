# 演示文档归属用户工作目录，而非应用私有数据目录

桌面应用的最初设计把演示文档存进应用私有目录（`userData/documents/`）；用户要求启动时指定工作路径，所有演示文档、资源、会话历史都放在该目录，拷贝整个目录即可在任意电脑用浏览器打开。故所有产物存放在用户指定的工作目录，应用不把文档藏进自身数据目录。

**Status**: accepted

**Considered Options**:
- 应用私有存储（`userData/`）—— 干净、隔离，但用户不可见、不可移植，违背"拷贝即用"的核心诉求
- 用户工作目录 —— 用户拥有并管理文件，可整体拷贝移植；代价是应用需容忍目录被移动/重命名/用户手动编辑

**Consequences**:
- 工作目录即产品边界：session 历史、meta、HTML、lib 全部跟随工作目录
- 应用只读写不删除用户文件；文档删除需二次确认
- 跨机器恢复对话依赖 session 文件随工作目录迁移（cwd 路径变化需容忍）
