# 提示词裁剪纪律：单源化、正说替代禁止、完成条件收敛

`PHYSICS_SKILL_PROMPT` 是每次生成都常驻的 system prompt，也是本应用唯一「随每个请求重发」的可编辑指令面。为了让「改提示词」这件事能被反复优化而不反弹，正文遵守三条纪律：

1. **单源化（single source of truth）**：一条规则只在一处展开，其余位置用指针（`见 §7 步骤 1`、见 `drawing.md` §6）。重复表述不只是 token，它逼模型在每一步**对齐多份表述**，直接变成 reasoning。
2. **正说替代禁止**：陈述目标行为（「公式一律用 `$...$`」「时刻表只取 §3 阶段边界」「主循环一律 `startLoop`」），不用禁止句——禁止句会重新点名被禁行为。正文不再出现「禁止 / 不得」；仅保留少数无法正说的判据性短句。
3. **完成条件收敛**：每步只留**一个可判定的闸门** + 该步真正落盘的那一笔；逐项自审清单集中在 §7 的 `check_demo` 核对（唯一真相源），不在各步复述。落盘锚点仍留在各步（ADR-0007 的教训：只写在 §7 会被忽略）。

**Status**: accepted

**Considered Options**:
- **把 `内容规则` 整节移出常驻**（更彻底的单源化）—— 沿用 ADR-0006 的实测否决：提示词 10178→8132 字符（−20.1%）后速度无收益（首个 `write` 491s vs 463s、回合 629s vs 495s），且 `angleArc` 归零——该节规则在别处没有真相源，移出即退化。故本轮只做**节内单源化**，不动该节
- **维持"多写一遍更保险"** —— 否决：ADR-0007 已实测「软约束 / 重复闸门 0/4 触发」，重复不换来遵守，只换来 token 与对齐成本
- **把完成条件的自审清单全部删除** —— 否决：那会把检查整个消掉（premature completion 风险）；改为收敛到 §7 一处，并把可机械化的部分交给 `check_demo`

**Consequences**:
- 正文规模基本持平（10911 → ~10000 字符）：消掉的重复被「两轮结构」的新表述抵消；收益不在常驻字节数，而在**模型每步要生成 / 对齐的令牌**
- 三处 leading word 保持复用、不再展开：`讲解点`、`图清单`、`反着摆`
- 新增 / 修改提示词时的验收：`test/skill-prompt.test.ts` 的文本契约（含 `not.toContain('禁止')` 与「骨架机制只展开一处」）+ `typecheck`
- 与 ADR-0006 的「内容规则整节恢复常驻」不冲突：那条讲**节的去留**，本条讲**节内与流程内的写法**
