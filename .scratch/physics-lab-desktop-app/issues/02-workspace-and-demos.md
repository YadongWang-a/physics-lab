# 02 — 工作目录与演示清单

**What to build:** 老师启动时选择工作目录（记住上次选择）；应用扫描其中所有演示 HTML，为每个演示维护独立会话与中文标题；重启后列表与会话完整恢复；删除演示需二次确认（ADR-0001/0002）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 首次启动引导选择工作目录；重启自动恢复上次目录（可更改）
- [ ] 扫描工作目录中演示 HTML 并列出（中文标题，无标题时显示文件名）
- [ ] 每个演示对应独立会话文件（一个 HTML 一个 session）；工作目录一份清单（demos.json）记录 文件↔会话↔中文标题↔创建时间 映射
- [ ] 重启应用后演示列表与各自会话完整恢复
- [ ] 删除演示需二次确认；删除后应用创建的会话文件一并移除（不触碰用户其他文件）
